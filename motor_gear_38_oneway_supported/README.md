# 旧ワンウェイクラッチ：駆動側ストッパー付きハブ

`motor_gear_38_oneway_supported_hub.stl` が交換用です。旧版の `motor_gear_38_oneway_gear.stl` と `motor_gear_38_oneway_cover.stl`、使用中の金属ねじを再利用します。鼓形ローラー版用ではありません。

## 変更点

バネ爪の自由端の背後に、中央ハブと一体の固定受けを3箇所追加しました。爪が駆動反力で時計回り側へ逃げると受けに当たる構成です。爪との初期隙間は半径24.6 mm付近で約0.34 mm（0.8度）。受けの最大半径は25.2 mmで、外ギアの内歯先端半径26 mmより0.8 mm内側です。

爪先形状、バネ厚1.2 mm、D穴、全高13 mm、蓋との隙間は旧版と同じです。回転方向も旧版と同じです。爪の内側を全面的に埋めず、半径内向きの退避空間を残しています。

## 印刷と交換

1. 交換用ハブだけPETGで印刷します。元のハブと同じ向きで、張り出し下面にサポートを使います。
2. サポートとバリを除去します。特に爪とストッパーの隙間が印刷でつながっていないことを確認します。
3. 蓋を外してハブを交換し、既存の蓋と金属ねじで組み戻します。
4. まず手で駆動方向の噛み込みと、逆方向の空転を旧版と比較します。その後、低負荷からモーター駆動時の歯飛び音を確認します。

## 確認済み範囲と限界

幾何学チェックは `verify_supported.scad` と `geometry_checks.json`、STLチェックは `mesh_checks.json` を参照してください。

- 初期位置で爪と受けが重ならないこと。
- 爪を剛体として1度時計回りにずらすと受けに当たること。
- 爪を半径内向きに0～2.2 mm平行移動させた指定経路で、受けと重ならないこと。
- 組立初期位置で、ハブと既存のギア・蓋に意図しない重なりがないこと。

**指定した剛体移動経路の確認は、実際のバネ変形や荷重解析とは異なります。** 曲がる爪が空転時にも受けに当たり、抵抗が増える可能性があります。歯飛びの改善、空転抵抗、保持トルク、疲労寿命は実機未検証です。改善しない、または空転が重くなる場合は、無理に回し続けず旧ハブと比較してください。

元のCAD・STLは変更していません。このフォルダの `motor_gear_38_oneway.scad` は旧版の参考コピーです。新しい編集対象は `motor_gear_38_oneway_supported.scad` です。歯形生成は親フォルダの `BOSL2` を参照します。STLの印刷にはBOSL2は不要です。
