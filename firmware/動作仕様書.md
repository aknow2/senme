# SENME Firmware 動作仕様書

作成日：2026年9月24日  
対象：`senme_controller`（ESP32コントローラー）  
根拠：現行の [Control.h](senme_controller/Control.h) と [senme_controller.ino](senme_controller/senme_controller.ino)

本書は現在のソースコードの動作を記載する。実機に書き込まれているバージョンや、実機での回転・波形を確認した結果ではない。揺れ検知送信機 `sense_sender` の動作は対象外とする。

## 1. 共通仕様

### 1.1 起動とモード切替

電源投入・リセット時は保存済み設定を読み込み、シーケンスモードの先頭から開始する。前回のモードや進行位置は復元しない。

ボタンを短押しして離すと、次の順序でモードが切り替わる。

```text
シーケンス → LED Edit（編集1） → Motor Edit（編集2） → ESP-NOW → シーケンス
```

モード切替に伴うモーター停止処理中とESP-NOWの実行受付後～運転終了までは、短押しによる次のモードへの切替を受け付けない。シーケンス内の通常減速区間では短押しによる切替が可能。無効期間中の操作は予約されない。

### 1.2 LEDの表示

| 表示 | 動作 |
| --- | --- |
| フェードイン・アウト | 5秒周期で明るさ0% → 100% → 0%を繰り返す。開始から2.5秒で最大、5秒で0%。sin波に相当する滑らかな変化 |
| 70%連続点灯 | モーター加速中の15秒間、明るさを70%に固定。フェードや設定周期の点滅は行わない |
| 設定値による点滅 | 55.55ms周期で繰り返し点灯。各周期の点灯時間はLED Editの設定値を使用。点灯中の出力は100% |

70%連続点灯は1kHz PWMのデューティ比70%で実現する。70%は制御値であり、測定した照度や人が感じる明るさの比率ではない。

点灯時間0msの場合、「点滅」区間でも消灯する。55.55msの場合は100%連続点灯になる。加速中の70%点灯と待機中のフェードは、この点灯時間設定の影響を受けない。

### 1.3 モーター出力

本書の「最大値」はMotor Editで設定した最大PWM出力率を指す。100%固定ではない。実回転数を測定・制御する機能はない。

| 項目 | 仕様 |
| --- | --- |
| 開始 | 15秒かけて45%から設定最大値まで直線的に上昇 |
| 通常停止 | 15秒かけて停止開始時の出力から45%まで直線的に下降し、15秒終了時に即0% |
| 45%の意味 | PWM出力率の絶対値45%。設定最大値の45%ではない |
| 停止開始時の出力が0%超～45%以下 | 出力を上げず、現在の出力を15秒維持した後、即0% |
| 既に出力0%でモード切替 | 減速のための15秒待機は不要 |

開始時はPWM出力を45%にし、15秒かけて設定最大値へ上げます。設定最大値が45%以下の場合は、その設定値を開始時から維持します（0%設定なら出力しません）。この開始処理はシーケンス・Motor Edit・ESP-NOWに共通です。

シーケンス・ESP-NOWは最大値が0%でも所定の時間配分とLED表示で進行する。
モード切替で途中停止する場合は、最大値に上げ直さず、直前に適用した実際のPWM出力から停止処理を開始する。
出力0%はモーターへの停止指令であり、軸の停止検知やブレーキ制御は行わない。

## 2. シーケンスモード

110秒を1周期として自動的に繰り返す。起動時、およびESP-NOWからこのモードへ戻った際は0秒から開始する。

| 経過時間 | 継続時間 | モーター | LED |
| --- | --- | --- | --- |
| 0秒以上～20秒未満 | 20秒 | 0% | フェードイン・アウトを4周期 |
| 20秒以上～35秒未満 | 15秒 | 45% → 設定最大値へ加速 | 70%連続点灯 |
| 35秒以上～95秒未満 | 60秒 | 設定最大値を維持 | 設定値による点滅 |
| 95秒以上～110秒未満 | 15秒 | 設定最大値 → 45%へ減速 | 設定値による点滅を継続 |
| 110秒 | 瞬時の切替 | 即0% | 明るさ0%からフェードを再開し、次の周期へ |

点滅は設定最大値に達する35秒時点で開始する。一定出力での点滅60秒に減速中の点滅15秒が加わるため、点滅区間全体は75秒となる。

短押しするとLED Editへ切り替わる。モーターが動いている場合は、LEDを設定値による点滅に切り替え、現在出力から15秒の停止処理を行う。停止処理中の追加短押しは無効。シーケンスの通常減速中に短押しした場合も、切替時点から改めて15秒かけて停止するため、元の停止予定より遅くなる。この延長は許容する。ロータリー操作・長押し保存・START受信は、このシーケンスモード中は無効。

## 3. LED Edit（編集1）

LEDの点滅周期内の点灯時間を調整するモード。通常はモーター出力0%だが、シーケンスから切り替えた直後はモーターの停止処理が最大15秒間継続する。

| 操作・項目 | 仕様 |
| --- | --- |
| LED | 現在の点灯時間設定で点滅 |
| 時計回り1クリック | 点灯時間を0.5ms増加 |
| 反時計回り1クリック | 点灯時間を0.5ms減少 |
| 設定範囲 | 0～55.55ms。範囲外へ回しても端の値で止まる |
| 初期値 | 5.0ms点灯／55.55ms周期 |
| 3秒長押し | LEDの点灯時間のみ保存 |
| 短押し | Motor Editへ切替。ただしモーター停止処理中は無効 |
| START | 破棄 |

点滅周期55.55msは固定で、ロータリーで変更されるのは点灯時間のみ。例えば設定5.0msなら、5.0ms点灯＋50.55ms消灯となる。
モーター停止処理中でも、LEDの調整と保存は可能。

点灯時間は0.5ms刻みで55.5msまで調整でき、その次が連続点灯の55.55msです。旧設定の56ms連続点灯は読み込み時に55.55msへ移行します。

## 4. Motor Edit（編集2）

モーターの最大PWM出力率を調整するモード。

| 入ってからの時間 | モーター | LED |
| --- | --- | --- |
| 0秒以上～15秒未満 | 45%から現在の設定最大値に向けて加速 | 70%連続点灯 |
| 15秒以降 | 現在の設定最大値を出力 | 設定値による点滅 |

| 操作・項目 | 仕様 |
| --- | --- |
| 時計回り1クリック | 最大値を1パーセントポイント増加 |
| 反時計回り1クリック | 最大値を1パーセントポイント減少 |
| 設定範囲 | 0～100%。範囲外へ回しても端の値で止まる |
| 初期値 | 45% |
| 3秒長押し | モーター最大値のみ保存 |
| 短押し | ESP-NOWへ切替し、モーター停止処理を開始 |
| START | 破棄 |

加速中に設定を変更した場合、`開始値 + (現在の設定最大値 − 開始値) × 入ってからの経過時間 ÷ 15秒`（開始値は45%と現在の設定最大値の小さい方） を出力する。15秒の計測をやり直すことはない。15秒経過後の設定変更は出力へ直接反映され、変更のたびに15秒の加減速を行うわけではない。

退出時は、LEDを設定値による点滅にし、現在のモーター出力から15秒で45%へ減速して即0%にする。加速途中の退出も同様。停止中は既にESP-NOWモードに移っているため、ロータリー操作・長押し保存は無効であり、STARTと追加短押しも受け付けない。停止完了後にLEDのフェードとSTART受付を開始する。

## 5. ESP-NOWモード

### 5.1 待機と運転

Motor Editから移った際は、前節の停止処理を終えてから待機に入る。待機中はモーター0%、LEDは明るさ0%から5秒周期のフェードイン・アウトを続ける。待機に時間制限はない。

有効なSTARTを1件受け付けると、その時点で後続のSTARTを受け付けなくなる。次のメインループ処理で60秒の運転を開始する。

| 運転開始からの経過時間 | 継続時間 | モーター | LED | 後続START |
| --- | --- | --- | --- | --- |
| 0秒以上～15秒未満 | 15秒 | 45% → 設定最大値へ加速 | 70%連続点灯 | 破棄 |
| 15秒以上～45秒未満 | 30秒 | 設定最大値を維持 | 設定値による点滅 | 破棄 |
| 45秒以上～60秒未満 | 15秒 | 設定最大値 → 45%へ減速 | 設定値による点滅を継続 | 破棄 |
| 60秒・停止完了 | 追加待機なし | 即0% | 明るさ0%からフェードを再開 | 受付再開 |

最大値維持は30秒。減速中も点滅するため、点滅区間全体は45秒。加速・維持・減速を合わせた運転時間は60秒。

メイン処理でモーターPWMを0%にし、LEDをフェードへ切り替える処理を行った後にSTART受付を再開する。停止後5秒の待機は設けない。再開後に新しいSTARTが届けば、すぐ次の運転を開始できる。

運転中に破棄したSTARTは保存・予約・再実行せず、運転時間の延長もしない。停止後に届く再送は、新しいSTARTとして扱う。

### 5.2 操作と通信

| 項目 | 仕様 |
| --- | --- |
| 待機中の短押し | シーケンスへ切替し、20秒のフェード区間から再開 |
| START受付後・運転中・Motor Edit退出時の停止中の短押し | 無効 |
| ロータリー操作／長押し保存 | 無効 |
| 運転設定 | LED EditとMotor Editの現在値を使用。未保存変更も使用 |
| 有効な本文 | ASCII `START` の5バイト、または末尾NULを含む6バイト |
| 無効な本文 | 小文字、改行付き、JSON、その他の長さ・内容 |
| Wi-Fiチャンネル | 1 |
| 送信元制限 | 送信元MACによる制限なし。暗号化なし |
| 実行受付の応答 | アプリケーション側のACKなし |

「受信不可」は、無線を停止する意味ではなく、アプリケーションでメッセージを破棄することを指す。ESP-NOW待機状態以外では本文を解析せず破棄する。送信成功だけでは、運転開始が受け付けられたとは判断できない。

## 6. 設定の保存

設定変更はすぐに有効になり、保存前でも別モードで使用される。再起動後も保持するには、対象の編集モードで3秒長押しする。

| 設定 | 保存するモード | 保存値がない場合 |
| --- | --- | --- |
| LED点灯時間 | LED Edit | 5.0ms |
| モーター最大出力 | Motor Edit | 45% |

長押し1回につき保存は1回のみ。長押し後にボタンを離してもモードは切り替わらない。他方の設定は同時保存されない。シリアルログに `SAVED` または `SAVE FAILED` を表示する。保存成功時のみ、LEDを明るさ100%で約3Hz、1秒間に3回点滅させる（約167ms点灯／約167ms消灯）。この間は通常のLED表示より確認点滅を優先し、1秒後に現在のモードの表示へ戻す。モーター制御やモードの時間計測は継続する。

保存領域を利用できない場合は初期値で開始し、RAM上での変更は可能だが保存はできない。不正な保存値は、その項目の初期値に戻す。

## 7. 実装上の時間精度と例外

- 各時間はFirmwareの制御時間。メインループの処理時間やOSのスケジューリングによる遅延がある。
- LEDの調光（1kHz）と点滅（55.55ms周期）の切替には、約55.55msの消灯が入る。表の切替時刻は論理上の時刻であり、実際の波形にはこの切替時間が含まれる。
- モーターPWMは20kHz・10bit。出力率には量子化がある。45%で一定時間保持する段階はなく、15秒の減速が終わると0%へ切り替える。
- 初期最大値45%のままでは、開始時から45%を維持し、停止区間も45%を15秒維持した後に0%となる。45%より上から減速する動作を確認するには、最大値を45%より大きく設定する。
- LED・モーター制御APIなどの異常時はSTARTを無効化し、最後に正常適用したPWM出力から15秒で45%まで下げた後、0%を指令する。45%以下は15秒維持し、既に0%またはモーター未初期化なら直ちにOFFを指令する。停止処理後にLED消灯を試み、リセット待ちに入る。停止中のAPI失敗で異常処理を再帰呼び出ししない。モーターAPI失敗時は減速を保証できない旨をログに残し、最終0%指令が失敗した場合は1秒ごとに0%を再試行する。API復旧後も運転は再開しない。電源断・CPU停止時の減速は保証しない。

直近の変更時に、[制御ロジックテスト](tests/control_test.cpp)とESP32向けコンパイルが成功している。テストはモードごとの時間境界、加速中のLED 70%、設定範囲、停止処理、START破棄と停止直後の再受付、ボタン操作、時計の桁あふれを対象とする。

ユーザーの変更依頼（2026年10月3日）により、現在の加速始点・減速終点は45%。45%での実機確認は未実施。
最新Firmware全体の実機検証状況、LED波形、電源ノイズ、保存・復元、ESP-NOW実通信の検証結果は本書では未確認。仕様書の更新によるFirmwareの動作変更はない。


## 9. レビューで確認済みの判断

以下はユーザー確認済みの仕様として維持する。

| 項目 | 判断・理由 |
| --- | --- |
| 加速の始点・減速の終点45% | ユーザーの変更依頼に基づく。減速は15秒で45%へ下げ、その後即0%とする。実機確認は未実施 |
| Motor Editの変更を即時反映 | ロータリーによる1パーセントポイント刻みの調整を前提としており、変更のたびの15秒加減速は不要 |
| 減速中のモード切替による停止時間の延長 | 切替時点から15秒の停止処理を再開する現行動作を許容する |

上記のレビュー指摘は、許容する仕様として解消済み。制御コードの修正は行わない。
