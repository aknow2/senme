# 旧版ワンウェイクラッチ：バネ腕1.4mm比較用ハブ

印刷するのは `motor_gear_38_oneway_thick_hub.stl` だけです。旧版 `motor_gear_38_oneway_gear.stl`、同cover、金属ねじを再利用します。

旧版のバネ腕の幅を1.2mmから1.4mmへ増やしました。同じパラメータを使うアンカー先端も太くなります。ストッパーはありません。爪先形状、D穴、全高13mm、回転方向は元のままです。

旧版と同じ印刷姿勢で、張り出し下面にサポートを使用してください。バネ腕の周囲のサポート・バリを取り除き、取り付け後は手回しで元のハブと比較してください。

カチカチ音は歯飛び以外に、ターンテーブルの惰性による追い越し空転でも発生します。重量だけで原因は断定できません。一定速のモーターを慣性だけで持続的に追い越すわけではありませんが、モーター側が減速・速度変動した瞬間に出力側が先行することは考えられます。

正常な追い越し空転が原因なら、厚肉化は必要とは限りません。バネを太くすると空転抵抗が増える可能性があります。駆動中に中央ハブが外ギアを追い越すのか、外ギアがハブを追い越すのかを目印・動画で確認してください。改善効果・空転抵抗・耐久性は実機未検証です。

CADソースは親フォルダの `motor_gear_38.scad` と `BOSL2` を参照します。元ファイルは変更していません。
