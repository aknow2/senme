# 正八角形の電子鈴

参考画像をもとにした試作モデル。単位は mm。OpenSCAD 2021.01 で使用でき、外部ライブラリは不要です。

## 開き方

`octagonal_bell.scad` をOpenSCADで開き、F5でプレビューします。
先頭の `part` を変更して表示を切り替えます。

| part | 表示 |
| --- | --- |
| assembly | 完成形 |
| section | 前半分を取り除いた断面・収納例 |
| exploded | 分解表示 |
| print | 印刷部品4点を平面上に配置 |
| body / lid / tray / shelf | 本体／上蓋／基板トレー／電池棚を個別表示、底面Z=0 |
| ball | 鈴玉の参考形状、底面Z=0 |

印刷には同梱の `body.stl`、`lid.stl`、`tray.stl`、`shelf.stl` を使用できます。寸法を変えた場合は各部品をF6でレンダリングしてSTLを再出力してください。完成表示の電池・基板は寸法確認用の箱です。

## 寸法と構造

- 正八角形の対辺180、対角約194.8、ロープ取り付け部を含め全高148.4（元の135から13.4延長）。
- 壁厚3、胴体の合わせ面Z=91.4、上蓋との隙間0.35、差し込み部の片側余裕0.3。
- Bodyの底面対辺は約128.3。サポートを減らすため旧100から拡大し、下部外周は八角形の頂点方向でも鉛直から45度以下の張り出しにしています。
- 電池135.5 × 69 × 16を中央の棚に横置き。棚の下にESP32 52 × 28 × 12とMPU6050 21 × 16 × 5の参考外形を横並びで配置。
- トレー上面から電池棚下面までの有効高さは30mm（`electronics_clearance`）。トレー底面Z=48を維持して電池棚下面をZ=80.4に上げ、合わせ面・肩・天井も13.4mm上げています。支柱の全高は32.4mm。基板の参考外形には実物の10mmピンやコネクター・配線を正確には反映していません。
- 下部は直径25の鈴玉用空間。基板トレーが電子機器と鈴玉を隔てます。
- 底面中央の音穴は幅4、全長90、両端の丸穴は直径10。ロープ穴は幅19 × 高さ14。
- 上蓋は前後2箇所のM3 × 35ねじと六角ナットで固定。本体側は直径3.4の通し穴と、内側から横差しできるナット受け（対辺6.0・高さ2.8）があります。ナット受け上面は合わせ面から19mm下（Z=72.4）、下面は21.8mm下（Z=69.6）です。外装の外側には開口しません。
- 電池棚は4箇所のM3ねじと六角ナットでトレーの支柱に固定。支柱はトレー底面まで直径3.4の貫通穴、裏面には対辺6.0・深さ2.6の六角ナットくぼみがあります（各部のナットは対辺5.5・厚さ2.4を想定）。

画像の対辺150では、厚さ3の壁と矩形の電池の角の間に余裕がありません。現在のモデルは対辺180に設定しています。電池外形は八角形に収まりますが、コネクター・ケーブルの曲げ・ケースの突起は含めていません。実物に応じて `battery` と `body_width` を調整してください。基板寸法・高さも仮定値です。

## 組み立て

1. トレー・電池棚を入れる前に、本体の前後の固定部へ内側の横穴からM3六角ナットを1個ずつ奥まで差し込み、ねじ穴を合わせます。ナット受けは電池棚より下にあるため、先に入れてください。その後、本体に直径25程度の鈴玉を入れます。
2. 基板を絶縁スペーサーや結束バンドでトレーに固定します。基板固有の取り付け穴は未設定です。
3. 本体に入れる前に、トレー裏面の4箇所の六角くぼみにM3ナットを入れ、電池棚の上からねじを通して支柱に固定します。棚上面からトレー裏面までは34.8mmです。頭の下から測って35mmのM3ねじ（皿ねじ以外・座金なし）なら裏面から約0.2mm突き出す設計です。実物のナット・ねじとの適合を確認してください。くぼみの余裕は `tray_nut_af` と `tray_nut_depth` で調整できます。
4. 棚を固定したトレーを本体内周の受けに載せます。
5. 電池を棚の長穴を使った結束バンドで固定し、奥側のケーブル口から配線します。
6. 上蓋の差し込み部を入れ、頭径6.6未満のM3 × 35で固定します（皿ねじ以外・座金なし）。ねじ先端は合わせ面から23mm下まで入り、ナット受け下面を1.2mm通過します。閉じるまでナットが横穴から抜けないよう本体を水平に保ってください。挿入余裕は `lid_nut_af` と `lid_nut_height` で調整できます。
7. ロープを上部の穴に通します。

トレー自体は受けに載せる方式です。振ったときの浮きやがたつきは試作確認の対象で、必要なら蓋側との間に緩衝材を追加してください。

30mmの隙間に変更する前の本体は高さが足りないため、新しいトレーと組み合わせる場合は本体も再印刷してください。トレー受けの高さと鈴玉の空間は維持しています。底に置いた参考鈴玉の上端とトレー下面の隙間は20mmです。

## 印刷と確認範囲

### 必要なねじ・ナット

| 用途 | 部品 | 数量 |
| --- | --- | --- |
| 上蓋と本体 | M3 × 35 なべ小ねじ（全ねじ、頭径6.6未満） | 2本 |
| 電池棚とトレー | M3 × 35 なべ小ねじ（全ねじ） | 4本 |
| 上蓋2箇所＋トレー4箇所 | M3六角ナット（対辺5.5・厚さ2.4想定） | 合計6個 |

M3 × 35なべ小ねじ6本とM3六角ナット6個に統一しています。座金なしで設計しています。ESP32・センサーの固定ねじは、基板の取り付け穴が未確定のため含みません。ナット式の上蓋固定に変更する場合、本体は新しい `body.stl` で印刷してください。

本体・トレー・棚はSTLの向きで底面を下にします。蓋はスライサーで差し込みリップ、天井、ロープ穴の下面を確認し、必要なサポートを付けてください。全パーツのサポート不要は保証していません。

### Bodyのサポートなし印刷向け変更（2026-09-26）

今回の変更はBodyのみです。蓋・トレー・電池棚の形状とSTLは変更していません。既存のM3×35ねじ・ナットを使い、Bodyだけ差し替えられます。

- トレー受けの下面に高さ6mmの斜面を追加。受け上面Z=48と受け幅を維持しています。
- 蓋用ネジ支柱の下端を壁から伸びる斜面に変更。ネジ位置、支柱上部の直径12mm、ナット挿入口の位置を維持しています。
- ナット穴の天井には0.3mmずつ2段の逃げを追加。最初は左右へ最大6mm、次は前後へ3.4mmを橋渡ししてから丸いネジ穴へつなぎます。ナットを受ける前後の平らな座面を残し、除去が必要な膜は設けていません。
- 底面の対辺を100mmから約128.3mmへ拡大。上部の対辺180mm、高さ91.4mm、音穴の寸法は維持しています。鈴室の下部形状が変わるため、音は実物で確認してください。

印刷時はSTLの底面を下にし、**サポートOFF、積層0.2mm以下**を想定しています。可変積層を使う場合もナット天井付近（Z=72.4〜73.0mm）は0.2mm以下にしてください。スライサーのプレビューで、最初の天井ブリッジが横穴の左右の壁を結んでいることと、次の段が前後を結んでいることを確認します。最初のブリッジを穴の奥行き方向へ走らせると片端が空中になるため、必要ならその層のブリッジ方向を調整します。

短いブリッジをサポートなしで印刷する設計ですが、成功は材料・冷却・スライサー設定にも依存します（[Prusaのブリッジ印刷解説](https://help.prusa3d.com/article/poor-bridging_1802)）。実機でのスライス・印刷は未確認です。

検証：BodyのCGALレンダリングは `Simple: yes`。STLは閉じた一体のメッシュで、鉛直から45度を超える下向き面は接地面とナット天井のブリッジ部分だけであることを確認しました。蓋・トレー・電池棚のCSGは変更前と一致し、Bodyとの体積干渉はありません（トレーはZ=48で面接触）。新しい断面は `body_supportless_section.png` を参照してください。既存の `preview.png`、`section.png`、`bottom.png` は変更前の参考画像です。

OpenSCADで4部品のCGALレンダリングとSTL出力を実行し、すべて `Simple: yes` を確認済みです。外観と断面のプレビューも作成しています。実印刷、ねじの保持力、吊り部の荷重試験、電子機器の実装は未確認です。防水構造ではありません。樹脂製の殻は金属鈴とは異なる音になるため、音質は試作で調整してください。

再出力例：

```sh
openscad -o body.stl -D 'part="body"' octagonal_bell.scad
```
