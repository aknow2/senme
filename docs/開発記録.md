# Zoetlamp 千目灯籠 開発記録

## zoetlamp

この1年ほど、「zoetlamp」という作品を個人で作り続けている。

名前は、ゾートロープ（zoetrope）とランプ（lamp）を組み合わせたもの。ランプシェードを回しながら光を点滅させると、表面の模様が動いて見える。そんなランプシェード型のゾートロープを作っている。

![zoetlampの動作の様子。](images/zoetlamp.gif)

## Burning Japan 2026、テーマは「千鬼夜行」

2026年のBurning Japanのテーマは「千鬼夜行 || Senki Yagyo」。
実は自分もこのテーマに投票していたので、決まったときから何か妖怪っぽい作品を作りたいと思っていた。
これまでのzoetlampでは、抽象的な模様が動くランプシェードを作ってきたけれど、今回はテーマに合わせて、もう少し具体的なモチーフを使ってみたい。

それと、せっかくBurning Japanに持っていくなら、いつもより大きなものを作りたい。
これまで作っていたzoetlampは直径18cm程度。それを今回は一気に60cmにすることにした。
なぜ60cmなのかというと、自分の部屋のドアからぎりぎり出せるサイズが50〜65cmくらいだったから。作りたい大きさと、部屋から運び出せる大きさの兼ね合いだった。

## 千目灯籠

デザインのモチーフに選んだのは、妖怪の「百目」。
ランプシェードいっぱいに目玉があって、それが回転と点滅によってうごめき始めたら、気持ち悪いし、きっと楽しい体験になるはず。
アニメーションもシンプルに作れそうなので、初めて大きなものを作るには、ちょうどよさそうだと思った。

作品名は、Burning Japanのテーマ「千鬼夜行」に合わせて「百目」から「千目」に。和風の名前にしたかったので、「ランプ」ではなく「灯籠」として、「千目灯籠」と名付けた。

## アニメーションの設計

これまでのzoetlampと同じように、球体にする前に、まずは平面で動きを考える。
平面なら、p5.jsやWebGLで動きを試しやすい。最初から3次元で考えられたら、また新しい道が開けるのかもしれない。

今回は、目玉を渦巻き状に並べて、外側に向かって一定の速さで動くパターンにした。これなら動きも分かりやすい。
ただ、単純な渦巻きだと余白が多くなる。そこで二重の螺旋にして、たくさんの目玉を並べられるようにした。最終的には432個の目玉が並ぶことになった。

## 目玉を動かしてみる

WGSLの勉強も兼ねて、「shaderbook」というWebアプリを作っていた。
このアプリにパラパラ漫画モードを追加して、目玉のアニメーションを作った。

![shaderbookのパラパラ漫画モード。目玉のアニメーションをコマごとに一覧表示している。](images/flipbook.png)

目玉の向きやまばたきの変化を、コマごとに確認できる。

## リソファン

ここまでできたら、あとは目玉の絵を球面に貼り付けたい。ただ、zoetlampでは絵をそのまま印刷するのではなく、「リソファン」という技法で光を透かして見せている。
明るく見せたい部分は薄く、暗く見せたい部分は厚く3Dプリントする。裏から光を当てると、厚みによって光の透け方が変わり、透かし絵のように絵が浮かび上がる仕組みだ。

![リソファンの様子。](images/rith.gif)

## シミュレーション＋3Dプリント用のアプリを作る

これまでのzoetlampは、一度の印刷で丸ごと出力できた。でも、今回は大きいので、いくつかに分けて印刷する必要がある。
ここで気になったのが、目玉の途中に継ぎ目が入ってしまうこと。それでアニメーションの見え方が崩れるかもしれない。そこで、目玉の周りに四角い枠を作って、目玉自体は分割しないデザインに変えた。

![赤と青の配置点の周りに四角い領域の境界線を引いた平面図。](images/withlines.png)

配置点の周りに枠を付けた図。目玉を収める領域を、渦巻きに沿って並べている。

形を確認しながら印刷データまで作れるように、次の流れで処理するアプリを作った。

1. 球面を、渦巻きに沿って並ぶ四角い領域に分割する。
2. 各領域に目玉のテクスチャを貼り付ける。
3. テクスチャの濃淡を厚みに変換して、リソファン化する。
4. 作成した3DモデルをSTL形式で出力する。

![球体シミュレータの画面。目玉のテクスチャを貼った球体と、形状や表示を調整する操作パネル。](images/sim.png)

球面に配置した目玉を3Dプレビューで確認し、形状を調整してSTLを出力する。

## 86ピースを溶接する

フィラメントはPETGを選んだ。PLAよりもしなりがあるのが、選んだ理由だ。球体を86ピースに分けて印刷して、それを溶接でつなぎ合わせていった。

つなぐときは基本的に摩擦溶接。隙間を埋めたいところや、もう少し強くしたいところには、はんだごても使った。摩擦溶接とはんだごての合わせ技で、球体に仕上げていった。

印刷から溶接まで、合わせておよそ1か月かかった。完成した球体の重さは約7kgになった。

## 全体の構造

![千目灯籠の構造断面図。球体の下部を台座と固定板で挟んで固定し、台座の下にギアとターンテーブルベアリングを配置する。中央にライト、右側にモーター、机の下段にESP32を置く。](images/senme-cross-section.png)

全体の仕組みはこんな感じになっている。球体を下から支える台座と、内側に置いた固定板で挟んで固定する。台座の下にはギアとターンテーブルベアリングがあり、横に置いたモーターの力をギアで伝えて回す。ライトは球体の中央に、制御用のESP32は机の下段に置いている。

手描きの断面図をもとに清書したものなので、寸法や部品の形は簡略化している。

## 球体をどう固定するか

球体の下側には、直径25cmくらいの穴が開いている。これを直径30cm、厚さ18mmの木の板に、どう固定するかを考えた。
板からはM4ネジが4本突き出ていたので、これを使えそうだった。下から支えるリングと、上から押さえる部品を用意して、その間にスポンジを挟む方法を考えた。
強く締め付けすぎるとPETGが変形するかもしれない。でも、回している途中で外れるのも困る。しっかり固定しつつ、取り外せるようにもしておきたかった。

最終的には、球体の下部を外側の台座と内側の固定板で挟み込む形で固定した。

## 大きな球体を回す

球体を作りながら、どうやって回すかも考えていた。
台座の上にターンテーブルベアリングを置き、その上にギアと球体を載せる構造だ。ベアリングは直径21cm程度のものを使い、中央には照明の光を通す穴を空けておく。
モーターの力をどう伝えるかも悩みどころだった。以前ベルトを使ったときは外れやすかったので、今回はギアを使う方向で考えた。大きい方のギアは直径22〜23cmくらいを想定して、モーターの回転数から歯数やギア比を考えていった。
ベアリングやギアの中心がずれないよう、OpenSCADでセンタリング治具も設計した。

シミュレーションでは、リフレッシュレートを17Hzにすると、回転数は43rpmになった。この数字は、あくまでシミュレーション上の条件だ。

## 急停止への対策

完成が近づいてきた頃、モーターの特性で気になることが出てきた。
選んだのは高トルクのモーターで、外から力をかけても簡単には回らない。いわゆる逆駆動がしにくいタイプだった。電源が突然落ちるとモーターが急停止し、回り続けようとする球体の慣性で固定部に大きな力がかかる。最悪の場合、目玉のパーツがばらばらに崩れてしまうのではないかと心配になった。
そこで、モーターで回すときには力を伝え、球体が惰性で回るときには空転できるように、ワンウェイクラッチを自作した。
いくつか構造を考えて試してみたけれど、最終的にはAIが提案した案が一番よかった。自分で考えたものよりAIの案がうまくいったのは、少し複雑な気分でもあった。

![ワンウェイクラッチの内部構造を示すCAD画像。外周のギアの内側に、中央のハブから伸びる3本の爪が配置されている。](../motor_gear_38_oneway_open.png)

自作したワンウェイクラッチの内部構造。

## 台座と電子制御

台座は高さ約50cm。上に直径60cmの球体を載せるので、全体の高さは約1mになる。
50×50cmくらいの木の板とVP16の塩ビパイプを使う構造を考え、内側にはモーターや電子回路を置く棚も作った。塩ビパイプの固定部品などはOpenSCADで設計した。
照明には24VのCOBタイプのLEDテープを使い、MOSFETで点滅や明るさを制御することにした。ゾートロープでは、回る速さと光が点滅するタイミングが大事になる。
実機では、調整用のロータリーエンコーダーを使って回転速度と光の点滅周期を調整した。
制御はArduinoからESP32に移すことを考え、離れた場所から起動できるようESP-NOWも試すことにした。
途中、24V・48WのLED回路でジャンパー接続部分が発熱し、ケーブルが溶けるトラブルがあった。配線や端子も、選び直す必要が出てきた。

## 作品をどうやって目覚めさせるか

起動装置も途中で何度か変わった。

神社の鈴緒を引くような仕組みも考えていた。ただ、嬬恋の風など、現地の環境に合わせてセンサーを調整するのが難しく、この方法はあきらめた。
最終的には、テーブルに黒い八角形の箱を置き、その箱を振って鈴を鳴らすと作品が起動する形になった。

鈴を鳴らすと千目灯籠が「目覚める」という演出だ。

## 屋外展示をどうするか

Burning Japanは屋外なので、雨や風への対策も必要だった。
最初は大きな傘のようなものや透明なドーム、PVCパイプを使ったティピー型やAフレーム型のシェルターなど、いろいろ考えた。
最終的には、手持ちのLOGOSのツールームテントを使うことにした。インナーテントを外して奥に作品を置き、手前にはゴザを敷いて観覧スペースにする。

## 酔っ払い対策として結界を張る

展示するときに気になったのが、本体を触られてしまうことだった。
今回のゾートロープは表面の模様が大事なので、汚れるとアニメーションの見え方が崩れるかもしれない。できれば本体にはあまり触ってほしくない。
なにしろ、メイカー系のイベントと違って酔っ払いが多い！ ということで、余ったフィラメントでお札を作り、結界を張ろうと考えた。

雰囲気を作ると同時に、なるべく作品に近づきすぎずに見てもらうためのアイデアだった。

## 会場のどこに置くか

僕はBurning Manで、Deep Playaに設置されたアートを探して歩くのが好きだ。街の中心から離れた場所で、「こんなところに、こんなものが？」と驚く。偶然そこに居合わせた人と「すごいな、これ」と言葉を交わすのが楽しかった。

もう一つ、技術的な理由もあった。今回の方式のゾートロープは周囲の明かりに弱い。周りが明るいと、点滅で作るアニメーションが見えにくくなるので、なるべく暗い場所に設置したかった。

そんな理由から、フリーキャンプエリアの奥の方に設置することになった。

## Appendix：技術スタック

### 構成ポンチ絵

![千目灯籠の構成ポンチ絵。MPU6050とESP32で揺れを検知し、ESP-NOWで受信側ESP32へ開始指令を送る。MOSFETを介してLEDとDCモーターを制御し、ギアで球体シェードを回転させる。](images/senme-system-overview.png)

黒い八角形の箱を振ると、MPU6050で検知した揺れをきっかけに送信側ESP32が`START`を送る。受信側ESP32はESP-NOWモードで待機しているときに指令を受け付け、照明とモーターを動かす。ロータリーエンコーダーはモード切替と設定に使う。

部品のつながりを説明するための図なので、外観・配線・寸法は簡略化している。内蔵imagegenで生成し、[生成プロンプト](images/senme-system-overview.prompt.txt)も保存している。

### シミュレータとCADデータ

| 対象 | 技術・形式 | 何に使うか |
| --- | --- | --- |
| 自作の球体シミュレータ | TypeScript、Three.js、Vite、HTML/CSS | 球体リソファンの3Dプレビュー、形状調整、STL出力。ブラウザ上で動くWebアプリ |
| シミュレータの開発環境 | Node.js 22.12以上、npm | 開発サーバー、ビルド、テスト。依存関係は[package.json](../simulator/package.json)に記録 |
| 機構部品のCAD | OpenSCAD、BOSL2 | ギア、支持部品、固定具、配線ボックス、八角形の筐体をコードで設計 |
| 設計・造形データ | SCAD、STL、SVG | SCADは寸法を変更できる設計ソース、STLは3Dプリント用のメッシュ、SVGはお札などの2D図形 |
| ギアの動作確認 | OpenSCADのアニメーション | 歯数比から回転角を計算して、かみ合いの様子を表示 |
| 球体の造形材料 | PETG | 本記録の球体は86ピースを印刷し、摩擦溶接とはんだごてで接合 |

ここでいう「シミュレータ」は、球体の形を確認して印刷データを作るためのアプリ。ギアのアニメーションも含め、荷重・摩擦・変形を解く物理解析ではない。起動方法は[simulator/README.md](../simulator/README.md)にまとめている。

### 電子パーツと制御

| 部品・技術 | 用途・記録されている仕様 |
| --- | --- |
| ESP32-WROOM系開発ボード | 揺れ検知送信側とLED・モーター制御側に各1台。ファームウェア資料にはELEGOO ESP-32（USB-C／CP2102）の記載あり |
| MPU6050 | 加速度を使った揺れ検知。ESP32とはI2Cで接続 |
| 押しボタン付きロータリーエンコーダー | モード切替、回転速度・光の点滅周期などの調整。型番は未記録 |
| 24V COBタイプのLEDテープ | 球体内部の照明。製作記録には24V・48WのLED回路の記述あり。商品型番は未記録 |
| ブラシ付きDCモーター | ギア機構を通じて球体を回転。商品型番・定格は未記録 |
| NチャネルMOSFET | LEDとモーターをそれぞれ駆動。型番は未記録 |
| 電池・負荷用電源 | 送信機とLED・モーターへの給電。電源の型番・電池容量は未記録 |
| ESP-NOW | ESP32間の開始指令の無線通信。ルーターへの接続は不要 |
| RMT／LEDC | ESP32の周辺機能。RMTでLED波形、LEDCでモーターPWMを生成 |
| Preferences／NVS | 設定値をESP32内蔵フラッシュに保存 |

配線や書き込みの手順は、[コントローラー](../firmware/README.md)と[揺れ検知送信機](../firmware/sense_sender/README.md)の資料にまとめている。ファームウェアの資料ではLEDを汎用的に扱っているけれど、ここでは実際の製作に使った24V COB LEDテープについて書いている。
