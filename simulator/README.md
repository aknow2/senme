# Senme Simulator

球体リソファンの3Dプレビュー・形状調整・STL出力用アプリです。旧experimentalを改名し、必要なソース・設定・テストをこのフォルダ内にまとめています。このフォルダだけを別の場所へコピーしても使用できます。

## 起動

Node.js 22.12以上とnpmが必要です。このフォルダで実行してください。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5174/ を開いてください。以前の `/experimental/` ではなく、ルートURLでアプリが起動します。
インストール済みなら `npm run dev` だけで起動できます。停止は `Ctrl+C` です。
ポートが使用中なら既存サーバーを停止するか、`npm run dev -- --port 5175` を使用してください。
HTMLの直接オープンではなく、Vite経由で使用します。

## ビルドと確認

```sh
npm run build
npm run preview -- --host 127.0.0.1
npm test
npm run test:typecheck
npm run lint
```

ビルド結果はこのフォルダ内の `dist/` に出力されます。previewのURLはターミナルに表示されます。

## データと構成

- `index.html`・`main.ts`・`styles.css`: 画面と起動処理
- ルートのその他の `.ts`: 形状生成・保存・バックアップ
- `src/`: 形状計算などの共通コード
- `images/`: テクスチャ設定から選択できるサンプル画像
- `tests/`: 形状生成・保存・バックアップのテスト

設定と登録画像はブラウザ内に保存されます。従来の保存キー・ZIP形式は互換性のため維持しています。同じブラウザ・ホスト名・ポートで開けば既存データを引き継ぎます。ホスト名・ポート・ブラウザを変更する場合は、旧画面のExportでZIPを保存し、新しい画面のImportで取り込んでください。
