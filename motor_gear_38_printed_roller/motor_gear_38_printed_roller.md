# 全印刷・2球式38歯ワンウェイクラッチ

円筒ローラーが倒れて起き上がれなくなる問題への試作として、転動体を **直径6 mmの球2個** に変更した。球はどの向きでも直径が同じなので、円筒のような「立った状態への復帰」を必要としない。既定形状は球。従来の円筒も `roller_shape="cylinder"` で出力できる。

38歯ギア・カム付きハブ・下側リング・蓋・固定ピンの寸法は変更しない。既存部品を使い、転動体2個を交換する試作。ファイル名は互換性のため `motor_gear_38_printed_roller` のままとし、`_roller.stl` の内容が球に変わっている。

## 使い方と出力

`motor_gear_38_printed_roller.scad` をOpenSCADで開く。既定は蓋を除いた内部表示。橙が外側ギア、青がカム付きハブ、黄土色が下側リング、緑が球。

| 設定 | 内容 |
| --- | --- |
| `roller_shape="ball"` | φ6 mmの球（既定） |
| `roller_shape="cylinder"` | 従来のφ6×8.4 mm円筒、上下0.3 mm面取り |
| `roller_state="free" / "wedge"` | 解放位置 / 噛み込み直前 |
| `render_part="open" / "assembly"` | 内部表示 / 蓋とピンを含む組立 |
| `render_part="exploded" / "layout"` | 分解表示 / 必要数の印刷部品配置 |
| `render_part="motion"` | 解放位置と噛み込み直前の間を往復する参考表示 |
| `gear / hub / ring / roller / cover / pin` | 部品単独出力 |

`motion` は位置関係の表示であり、摩擦・転がり・変形のシミュレーションではない。

親フォルダの `../motor_gear_38.scad` と `../BOSL2/` に依存する。このフォルダだけを別の場所へ移さない。

## 印刷するもの

| STL末尾 | 個数 | 形状・印刷方向 |
| --- | ---: | --- |
| `_gear.stl` | 1 | 38歯外側ギア。底面を下。既存品を流用 |
| `_hub.stl` | 1 | D穴カム本体、高さ10.9 mm。平らなカム下面を下。既存品を流用 |
| `_ring.stl` | 1 | 下側支持リング、外径20 mm・厚さ2.1 mm。既存品を流用 |
| `_roller.stl` | 2 | **φ6 mm球。下側にサポートが必要** |
| `_cover.stl` | 1 | 保持蓋。既存品を流用 |
| `_pin.stl` | 3 | 割り入り摩擦保持ピン。頭を下。既存品を流用 |

PETG球は中実で印刷する。平面カットを設けていないため、球単体をそのままベッドに置いたサポートなしの印刷は想定しない。スライサーで下半分を支えるサポートを設定する。0.4 mmノズルなら層厚0.16 mm程度を試作の出発点とするが、造形品質は未検証。

サポート痕・シームの突起・糸引きを除去し、複数方向の直径と滑らかさを確認する。**大きな平面を削り出すと、向きによって接触寸法が変わる。** 球を作る目的に反するため、形を崩すほど削らない。小径球の精度はプリンターに依存する。

```sh
# 既定の球を1個出力（印刷時に2個へ複製）
openscad --hardwarnings -D 'render_part="roller"' -o ball_6mm.stl motor_gear_38_printed_roller.scad

# 従来の円筒を出力
openscad --hardwarnings -D 'render_part="roller"' -D 'roller_shape="cylinder"' -o cylinder_6mm.stl motor_gear_38_printed_roller.scad
```

## 球が収まる位置

- ギア全厚13 mm、外側受け面の半径28 mm、D穴F7 / C0.06は従来どおり。
- 床Z=1.8 mm、蓋下面Z=11.2 mmで、転動体の空間高さは9.4 mm。φ6球には合計3.4 mmの上下移動余裕がある。
- 球の中心は、床に接したときZ=4.8 mm、蓋に接したときZ=8.2 mm。どちらもカム側面のZ=2.1〜10.9 mm内にあり、赤道部分でカムと外周に接触できる。
- 表示では床から0.04 mm浮かせる。横方向も外周・カムへの噛み込み直前に各0.04 mmのすき間を置く。
- 解放角49度、噛み込み直前角約30.31度。直径を維持したので平面上の接触位置は円筒版と同じ。

## 回転方向と組立

+Z（上面）から見てモーターハブを反時計回りに駆動すると、転動体が狭い側で噛む想定。停止後は外側ギアが反時計回りに追い越し、広い側へ移って解放される。112歯ターンテーブルは時計回り。`reverse_direction=true` で鏡像にできる。

1. 下側リングとハブ本体のD穴の平面を揃え、同じ軸に通す。リングの入口面取りを下にする。
2. 広いポケット2箇所へ球を1個ずつ入れる。姿勢合わせは不要。
3. 蓋を付け、印刷ピン3本で保持する。モーター軸全体からの抜け止めは別途必要。
4. 手でハブを固定し、外側ギアが反時計回りに空転し、時計回りに噛むか確認する。
5. 噛ませた直後に逆へ回し、解放できるか確認する。傾けて球が床側・蓋側へ移った後も繰り返す。
6. 続いて無負荷・低速で確認し、球・カム・受け面にへこみが生じていないか調べる。

固定ピンは直径3.3 mm、穴3.15 mmの摩擦保持。挿入力・保持力は実機調整が必要。

## 限界と確認事項

球化で取り除くのは、円筒が倒れたままになる姿勢の問題。バネを追加していないため、狭い側への移動遅れや、摩擦・変形による噛み付きまで解消するものではない。

球は円筒より接触面が小さく、同じ荷重では局所的な変形が懸念される。PETG球やカムがへこんで解放しにくくなる可能性がある。一般的な球の点接触・ローラーの線接触の説明は[SKFの軸受基礎資料（20ページ）](https://cdn.skfmediahub.skf.com/api/public/0901d196802809de/pdf_preview_medium/Rolling_bearings_-_17000_1_EN_pdf_preview_medium.pdf)を参照。この試作の強度評価を示す資料ではない。

指定モーターの表記10 kgf·cm（約0.98 N·m）、160 RPMでの伝達能力・解放・摩耗寿命は未検証。CAD確認は形状と可動空間を対象とし、実負荷性能を保証しない。

## 球形版のCAD確認（2026-10-01）

- OpenSCAD 2021.01の`--hardwarnings`で球のSTLを出力。単一の連結体・閉じたメッシュ・面の向きの整合を確認。
- STL外形は各軸約5.99884 mm（球面の多角形近似）、体積約113.025 mm³。公称φ6球の体積は約113.097 mm³。
- カムの線分との距離を噛み込み直前〜解放位置の41点で計算し、球表面とのすき間が約0.04 mm以上あることを確認。解放位置では約0.710 mm。噛み込み直前から狭い側へ2度進めると約0.032 mm食い込む計算になる。
- 床・蓋それぞれに接したときも、球の赤道がカムの高さ範囲内にあることを確認。これは幾何学的な確認であり、球の運動解析ではない。
- 円筒オプションも再出力し、高さ8.4 mmを確認。
- 内部・分解・印刷配置の画像を球形版へ更新し、目視確認。


## 大きめの球の比較試作

既存のφ6球・ギア・カムを変更せず、球だけ交換する比較用STLを追加した。

| ファイル | 公称径 | 既存カムの解放位置でのすき間（計算値） |
| --- | --- | --- |
| `motor_gear_38_printed_roller_ball_6p1.stl` | 6.1 mm | 約0.61 mm |
| `motor_gear_38_printed_roller_ball_6p2.stl` | 6.2 mm | 約0.51 mm |

各サイズを2個ずつ印刷し、同じ径の球をペアで使う。まず6.1 mmで、噛み始めと解放の軽さを手回し確認し、必要なら6.2 mmを試す。サポート除去・表面仕上げ後の実測径も確認する。形状チェックは通過しているが、噛み合い・解放・耐久性は実機未検証。

書き出し時は `render_part="roller"`、`roller_shape="ball"`、`roller_d=6.1` または `6.2` を指定した。**このSCADではroller_dを変えるとカム寸法も追従するため、この比較では球だけを書き出す。ギアやハブを再生成しない。** 表のすき間は追従後のカムではなく、元の6.0 mm用カムを固定して別計算した値。
